# 🎮 Pixel Auto Battler — Orchestrator Balanced Edition

เกมแนว **Auto Battler (วางแผนต่อสู้อัตโนมัติ)** สไตล์ภาพเรโทรพิกเซล (Pixel Art) ที่ออกแบบและควบคุมการพัฒนาด้วยระบบ **Orchestrator Architecture** โดยเน้นการจัดสมดุลทางคณิตศาสตร์ (Mathematical Class Balance) สูงสุดในรูปแบบ **Rock-Paper-Scissors Pentagram** เพื่อให้มั่นใจว่าจะไม่มีคลาสใดครองเกมเพียงคลาสเดียว และทุกกลยุทธ์มีตัวแก้ทางที่ชัดเจน

---

## 🌟 จุดเด่นของเกม (Key Highlights)

1. **ระบบคลาสที่สมดุลสมบูรณ์แบบ (5-Class Balanced Pentagram)**:
   - ผ่านการทดสอบและปรับแต่งค่าสเตตัสด้วย **Monte-Carlo Combat Simulator** จำลองการดวลนับ 1,000 ครั้งในทุกคู่ประกบ
2. **กราฟิกเรโทรพิกเซลแท้ (Procedural Pixel Art)**:
   - วาด Sprite พิกเซลขนาด 16x16 / 24x24 ผ่าน HTML5 Canvas แบบ `pixelated / crisp-edges`
   - เอฟเฟกต์แอนิเมชัน การกะพริบเวลารับดาเมจ (Hit Flash), ละอองอนุภาคเมื่อตัวละครตาย (Dissolve), ตัวเลขลอย (Floating Combat Text)
3. **ระบบเสียงสังเคราะห์ 8-bit ชิปจูน (Chiptune Web Audio Synthesizer)**:
   - เสียงเอฟเฟกต์สังเคราะห์ความถี่ Square / Sawtooth / Sine / Noise ในตัว ไม่ต้องโหลดไฟล์เสียงภายนอก
4. **ระบบเศรษฐกิจและการอัปเกรดแบบ Auto Battler มาตรฐาน**:
   - สะสมยูนิตซ้ำ 3 ตัวเพื่อรวมเป็น **2 ดาว (★★)** และ 3 ตัวของ 2 ดาวเพื่อรวมเป็น **3 ดาว (★★★)**
   - ระบบดอกเบี้ยเงินเก็บ (Interest 1 ทองต่องานเก็บ 10 ทอง สูงสุด 5 ทอง) และโบนัสชนะ/แพ้ต่อเนื่อง (Streak)
   - ปรับความเร็วการต่อสู้ได้ 1x, 2x, 4x

## ⚖️ การออกแบบความสมดุลของคลาส (Class Balance Design)

ความสัมพันธ์ของทั้ง 5 คลาสถูกออกแบบเป็นรูป **เบญจรงค์ (Pentagram Counter Cycle)**:

```
                  🛡️ KNIGHT (อัศวิน)
                 /                 \
     (ชนะ Rogue)                      (แพ้ Mage)
               /                     \
🗡️ ROGUE (นักฆ่า) <----------------- 🔮 MAGE (จอมเวท)
      \           (ชนะ Mage / Archer)         /
  (ชนะ \                                     / (แพ้ Cleric)
  Cleric)                                   /
         \                                 /
          🏹 ARCHER (พลธนู) ---------> ✨ CLERIC (นักบวช)
                      (ชนะ Cleric / Sustain)
```

### 1. รายละเอียดคลาสและสถิติพื้นฐาน (Class Overview)

| สัญลักษณ์ | คลาส (Class) | บทบาท (Role) | สเตตัสเด่น | ได้เปรียบ (Counter) | เสียเปรียบ (Weak To) |
| :---: | :--- | :--- | :--- | :--- | :--- |
| 🛡️ | **Knight (อัศวิน)** | แทงก์กายภาพ / CC | HP 680-1200, Armor 50-65 | Rogue, Archer | Mage |
| 🔮 | **Mage (จอมเวท)** | เบิร์สเวทหมู่ / ทะลุเกราะ | Attack เวท, Spells รุนแรง | Knight | Rogue, Cleric |
| 🗡️ | **Rogue (นักฆ่า)** | ล้วงแนวหลัง / คริติคอล | กระโดดไปแถวหลัง, Crit 2.2x | Mage, Archer, Cleric | Knight |
| 🏹 | **Archer (พลธนู)** | ดาเมจกายภาพระยะไกล | Range 5-6, Attack Speed ไว | Cleric, Skirmishers | Rogue, Knight |
| ✨ | **Cleric (นักบวช)** | ฮีลทีม / ต้านทานเวท | MR 55-75, ฮีลต่อเนื่อง | Mage | Rogue, Archer |

### 2. ผลการจำลองการต่อสู้จริง 1v1 (Monte-Carlo Balance Matrix - 500 Matches)

ตารางแสดงอัตราการชนะ (%) ของ **ผู้โจมตี (แถวแนวนอน)** เมื่อปะทะกับ **ผู้ตั้งรับ (คอลัมน์แนวตั้ง)**:

| ผู้โจมตี \ ผู้ตั้งรับ | Galahad (Knight) | Pyromancer (Mage) | Shadowblade (Rogue) | Woodsman (Archer) | Acolyte (Cleric) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Galahad (Knight)** | 50.0% | **7.5%** | **100.0%** | **100.0%** | **92.8%** |
| **Pyromancer (Mage)** | **96.1%** | 50.0% | **0.9%** | **93.3%** | **0.0%** |
| **Shadowblade (Rogue)**| **0.0%** | **99.9%** | 50.0% | **87.9%** | **34.9%** |
| **Woodsman (Archer)** | **0.0%** | **6.3%** | **15.7%** | 50.0% | **6.0%** |
| **Acolyte (Cleric)** | **11.0%** | **100.0%** | **67.4%** | **94.6%** | 50.0% |

> [!IMPORTANT]
> **หลักการลดทอนความเสียหาย (Damage Mitigation Formulas)**:
> - **กายภาพ (Physical):** `ดาเมจจริง = ดาเมจดิบ × (100 / (100 + เกราะเป้าหมาย))`
> - **เวทมนตร์ (Magic):** `ดาเมจจริง = ดาเมจดิบ × (100 / (100 + ต้านทานเวทเป้าหมาย))`
> - **การเก็บมานา (Mana Gain):** ได้รับ +10 มานาเมื่อโจมตีสำเร็จ, +8 มานาเมื่อได้รับความเสียหาย

## 🧩 บัพความสัมพันธ์คลาส (Class Synergy Traits)

เมื่อจัดทีมที่มีคลาสเดียวกันลงบนสนาม (นับยูนิตที่ไม่ซ้ำตัวกัน) จะปลดล็อกโบนัสทีม:

- **🛡️ Knight (2/4):**
  - **(2) ตัว:** อัศวินทั้งหมดได้รับ **เกราะ +35 (Armor)**
  - **(4) ตัว:** อัศวินได้รับเกราะ **+80** และพันธมิตรทั้งทีม **ลดดาเมจที่ได้รับ 20%**
- **🔮 Mage (2/4):**
  - **(2) ตัว:** จอมเวทได้รับ **พลังเวท +40%** และเริ่มต่อสู้ด้วยมานา 25
  - **(4) ตัว:** พันธมิตรทั้งหมด **พลังเวท +80%** และสกิลลดต้านทานเวทเป้าหมาย 40%
- **🗡️ Rogue (2/4):**
  - **(2) ตัว:** นักฆ่าทั้งหมดเพิ่ม **โอกาสคริติคอล +30%** และความแรงคริ +50%
  - **(4) ตัว:** นักฆ่า **คริติคอล 100% ใน 4 วินาทีแรก** และได้รับอัตราหลบหลีก +35%
- **🏹 Archer (2/4):**
  - **(2) ตัว:** พลธนูทั้งหมดได้รับ **ความเร็วโจมตี +40%**
  - **(4) ตัว:** พลธนูทั้งหมดได้รับ **ความเร็วโจมตี +90% และยิงทะลุเกราะ 40%**
- **✨ Cleric (2/4):**
  - **(2) ตัว:** พันธมิตรทุกคน **ฟื้นฟูพลังชีวิต 5% ของ Max HP ทุกวินาที**
  - **(4) ตัว:** พันธมิตร **ฟื้นฟู 10% Max HP ทุกวินาที** และนักบวชได้รับต้านทานเวท +60

## 🚀 วิธีเปิดเล่นเกม (How to Run)

เกมนี้เขียนด้วย **Vanilla JavaScript (ES Modules)** โดยไม่ต้องติดตั้ง dependencies เสริมใดๆ สามารถเปิดเล่นได้ 2 วิธี:

### วิธีที่ 1: รันผ่าน Local Web Server (แนะนำ)
เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วใช้คำสั่งใดคำสั่งหนึ่งด้านล่าง:

```bash
# ใช้ npx serve
npx serve .

# หรือใช้ Python
python -m http.server 8000
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000` (หรือพอร์ตที่ระบบแจ้ง)

### วิธีที่ 2: ดับเบิลคลิกเปิดไฟล์ `index.html`
หากเบราว์เซอร์ของคุณเปิดให้โหลด Local ES Modules สามารถดับเบิลคลิกไฟล์ `index.html` เพื่อเล่นได้ทันที

## 🕹️ คู่มือการเล่น (Gameplay Instructions)

1. **ช่วงเตรียมทัพ (Preparation Phase):**
   - **ซื้อตัวละคร:** คลิกที่การ์ดในร้านค้าด้านล่าง (ราคา 1 🪙 หรือ 3 🪙)
   - **วางลงสนาม:** คลิกที่ตัวละครบนม้านั่งสำรอง (แถบล่างสุด) แล้วคลิกที่ช่องบนกระดาน (แถวที่ 4, 5, 6 เป็นแดนผู้เล่น)
   - **เพิ่มจำนวนยูนิต:** กดปุ่ม **"ซื้อ XP (+4)"** ด้วย 4 ทอง เมื่อเลเวลอัปจะสามารถวางตัวละครลงสนามได้มากขึ้น (สูงสุด 8 ตัว)
   - **รวมดาว:** สะสมตัวละครชื่อเดียวกันระดับ 1 ดาว ครบ 3 ตัว ระบบจะรวมเป็น **2 ดาว (★★)** อัตโนมัติ!
   - **สุ่มร้านใหม่:** กดปุ่ม **"สุ่มร้านค้าใหม่"** เสีย 2 ทอง
2. **ช่วงต่อสู้ (Combat Phase):**
   - กดปุ่ม **"⚔️ เริ่มต่อสู้ (Ready)"** ตัวละครจะเริ่มเดินและเล็งเป้าหมายอัตโนมัติ
   - สามารถกดปุ่ม **"1x SPEED"** เพื่อเร่งความเร็วเป็น 2x หรือ 4x ได้
3. **ตรวจสอบความสมดุล:**
   - กดปุ่ม **"⚖️ ตารางสมดุล"** ที่มุมขวาบนเพื่อเปิดดูตาราง Counter Matrix และคำแนะนำได้ตลอดเวลา
